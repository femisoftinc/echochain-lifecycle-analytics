# EchoChain - Circular Economy & Secondary Market Lifecycle Analytics

## Internship Project

This project is developed as part of the Infotact Solutions Data Analytics & Engineering Internship.

## Problem Statement

Manufacturers usually stop tracking products after they are sold.
This project analyzes second-hand market data and warranty information to identify products that have high refurbishment and resale potential.

## Objectives

- Collect secondary market data
- Clean and transform data
- Analyze product lifecycle
- Calculate Circularity Score
- Build an Executive Power BI Dashboard

## Technology Stack

- Python
- SQL
- Power BI
- GitHub
- Databricks (Later)
- PySpark (Later)
